# CCL-Docs

Documentation for **Creative Coding Lab**, a platform I'm building for my own exploration and self-learning through programming.

The project combines a shared platform with interactive experiments inspired by ideas I find in books and online. These documents record the design, technical decisions, and development practices. You're welcome to use them to understand the project or build your own experiments.

## Documents

- [Getting Started](getting-started.md): project introduction and intended user experience.
- [Developer Architecture](developer-architecture.md): technical structure, workflows, and design decisions.
- [Coding Standards](coding-standards.md): the practices I follow when developing the project.
- [Design v0.8](Archive/creative-coding-lab-design-v0.8.md): the consolidated source design.

## Project status

The project is moving into initial setup and development. The documents describe the intended design and will evolve with implementation.

Follow progress on the [development board](https://github.com/users/Broomfields/projects/5). Design iterations are kept in `Archive/`.
